# pi-skill-retro

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-retro)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**retro** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Conduct a retrospective on a coding session.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-retro
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-retro.git ~/.pi/agent/skills/retro

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-retro.git ~/.agents/skills/retro
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:retro
```

Or let Pi automatically route to it based on conversation context and need.
